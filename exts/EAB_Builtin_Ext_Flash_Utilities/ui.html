Connection troubleshooting

Press Scan; the connected EVE chip is detected automatically. FT4222 and MPSSE adapters are supported with any EVE chip supported by the selected flash operation.

If cannot detects the board, check that it is powered, the SPI connections are correct, and the FTDI adapter uses the FTDI D2XX/bus driver (ftdibus.inf, shown as USB Serial Converter). WinUSB or USB COM drivers, often installed with Zadig, are not compatible.

Pico programming writes the image through uf2conv4eve and the USB drive. Hold BOOTSEL while plugging the Pico in, wait for RPI-RP2, then press Program on the Program tab. The image is built for —. Program is the only action a Pico can run — uf2conv4eve has no detect, read, verify, erase or NAND command, so the other buttons stay greyed; select an FT4222 or MPSSE adapter for those.

Program writes each queued image with its own flash_prog run, one after another: image n starts where image n−1 ended, padded up to Padding bytes (0 = straight after), so every row reports its own result. The queue stops and marks the rest does not fit when the next image would pass the end of the flash. Program needs a BT817, BT818 or BT82X board. Install Blob writes the flash driver into the first block, Update erases only what it needs (first image), Erase wipes the whole chip including the blob.

🍓 Program through a Raspberry Pi Pico

        
      


      

        

          
Shipped with this extension — nothing to download

          
    
            
  • native/uf2conv4eve.execonverts the image to UF2 and copies it to the Pico drive
    • 
            
  • pico/eve_flash_pico.uf2Pico program that runs from RAM and turns the board into an EVE flash programmer
    • 
            
  • flash_blob/BT815/6 and BT817/8 flash firmware blobs baked into that UF2
    • 
          

          
No Python, no Pico SDK and no separate uf2conv install is needed. The only requirement is a USB data cable (a charge-only cable never shows the drive).

        


        

          
1 · Wire the Pico to the EVE board

          

            
Pico pinEVE

            
              
GP2→SCK

              
GP3→MOSI

              
GP4→MISO

              
GP5→CS#

              
3V3 / VSYS→board power

              
GND→GND

            
          

          
This is the pin map of the BridgeTek MM2040EV board and the GD3X dazzler.

        


        

          
2 · Put the Pico in BOOTSEL mode

          
    
            
  1. Unplug the Pico.
    2. 
            
  2. Press and hold BOOTSEL on the Pico.
    3. 
            
  3. Plug the Pico into the PC while still holding BOOTSEL.
    4. 
            
  4. Release BOOTSEL once the RPI-RP2 drive appears in Explorer.
    5. 
            
  5. Press Check connection below — the Pico row turns Connected and is selected automatically.
    6. 
            
  6. Go to 🔌 Flash Programmer → Program and pick your .bin; the extension builds the UF2 and writes it to the drive.
    7. 
          

          
eve_flash_pico.uf2 runs from RAM: after the first write the drive reappears as BTEVE-FLASH, which is the Pico programming your EVE flash. Unplugging the Pico clears that state.
