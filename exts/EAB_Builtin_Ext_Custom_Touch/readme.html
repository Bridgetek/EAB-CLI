JTC - The Custom Touch Firmware Compiler

JTC aims to make it much easier to build custom touch firmware. It accepts small programs in a tiny C-like language and produces a loadable firmware image for custom touch controller.

The Language

The tiny language resembles C in syntax. It allows:

* functions, of void and int type
* if .. else constructs, while and do .. while loops
* local variables, of int type only (note: up to 3 local variables can be defined)
* integer arithmetic (no / or %)

The end-user defines three functions:

* i2c_addr() - which returns the I2C device address
* setup() - one-time initialization
* loop() - poll the CTP and update the touch sensing registers

By default, JTC allows 8-bit I2C register addressing. Adding these two macro definitions at the beginning of the user's code will change it to allow 16-bit I2C register addressing:


#config I2C_ADDRSIZE 16

#config I2C_ADDRENDIAN BIG // default

#config I2C_ADDRENDIAN LITTLE

In addition a number of built-in functions are available for IO in the user's code. Together these form a simple HAL.

* void delay_ms(n) - delay for n milliseconds
* void delay_us(n) - delay for n microseconds
* void i2c_regwr(u, v) - write value v to register u
* void i2c_startread(u) - start a read from register u
* int i2c_read16le() - read 16 bits from I2C, little-endian
* int i2c_read16be() - read 16 bits from I2C, big-endian
* int i2c_read8() - read 8 bit from I2C
* void i2c_stop() - end the I2C read
* void report_touch(id, x, y) - set the touch sensing registers, id=0-4, x/y 15-bit values
* int getINT() - get the INT input
* void setINT(u) - when u = 0: sets CTP_INT_N pin to drive low;
when u = 1: sets CTP_INT_N pin to Hi-Z (input)
* void setWAKE(u) - when u = 0: sets CTP_RST_N pin to low;
when u = 1: sets CTP_RST_N pin to high
* int getCYA() - get the register REG_TOUCH_CONFIG value

Compiler

The compiler accepts a single file as input, and outputs the firmware image.
The firmware image is packed in the form of EVE command codes in the xx.load.h file.

Validation

The compiler is validated using Focaltech and Ilitek sample codes. The compiled firmware image is compatible with BT88X/FT81X, BT815, and BT817, but not with other EVE chips.
When execute, load the codes in xx.load.h file into the command FIFO, and execute till finish. The custom touch function will take effect right after the command FIFO finishes.

Debug

Users have the option to utilize the printf() function within the source code of custom touch firmware to display debug messages on the LCD screen. The prototype of printf() is as follows, with its definition adhering to the standard C API printf() in <stdio.h>:
int printf(const char *format, ...)

To enable this functionality, the following steps must be taken:
1. Following a successful boot-up of EVE, ensure that the video timing registers (REG_HSIZE, REG_VSIZE, REG_PCLK, etc.) are configured correctly. These settings should align with the specifications of the connected LCD screen.
2. Download the custom touch firmware to RAM_CMD and wait for its execution to complete.
3. Load the debug support patch into RAM_CMD and wait for its completion of execution. The debug support patch can be found at <EAB Install>/Assets For Test/Custom Touch Test/debug/. Within this directory, jtcdebugxxx.load.h represents the text form, while jtcdebugxxx.load.bin represents the binary form.

At this point, the debug message should be displayed on the LCD screen if it is triggered.
It's crucial to emphasize that the debug function should be disabled during the production phase to optimize performance.

Example

Pseudo code on how to debug the custom touch firmware

/***
Assume that EVE boot-up sequence is properly done before this routine.
Both the custom touch firmware and the debug support patch are pieces

of code that can be executed by EVE coprocessor, so the routine will do:
1) Load the firmware into RAM_CMD
2) Update REG_CMD_WRITE then wait until the execution completes (REG_CMD_READ==REG_CMD_WRITE)

3) Load the debug support patch into RAM_CMD

4) Update REG_CMD_WRITE then wait until the execution completes (REG_CMD_READ==REG_CMD_WRITE)
***/


function load_and_execute(file_name):

// Read the content into local memory
content = read(file_name, "b");

// Write the content into RAM_CMD
EVE_Hal_wrMem(RAM_CMD, content, sizeof(content));

// Update the write pointer register to start the execution

EVE_Hal_wr32(REG_CMD_WRITE, sizeof(content));


// Wait until EVE completes all the commands

while (EVE_Hal_rd32(REG_CMD_READ) != EVE_Hal_rd32(REG_CMD_WRITE));


// Load and execute custom touch firmware
load_and_execute("custom.load.bin");


// Load and execute debug support patch

load_and_execute("jtcdebug.load.bin");


// DONE

Pseudo-code on how to use custom firmware

/***
Assume that EVE boot-up sequence is properly done before this routine.
The custom touch firmware is a piece of code that can be executed by EVE coprocessor,
so the routine will do:
1) Read the firmware into local memory or use the .load.h file
2) Write the firmware into RAM_CMD
3) Update the register REG_CMD_WRITE to start execution
4) Wait till the execution is done (REG_CMD_READ==REG_CMD_WRITE)
***/

// Read the custom touch firmware 'output.load.bin' into local memory
custom_touch_content = read("output.load.bin", "b");

// Write the custom touch firmware into RAM_CMD
EVE_Hal_wrMem(RAM_CMD, custom_touch_content, sizeof(custom_touch_content));

// Update the write pointer register to start the execution

EVE_Hal_wr32(REG_CMD_WRITE, sizeof(custom_touch_content));

// Wait till EVE completes all the commands

while (EVE_Hal_rd32(REG_CMD_READ) != EVE_Hal_rd32(REG_CMD_WRITE));

// DONE


Pseudo-code on how to use Goodix with I2C address 0x05d0 in BT88X/FT81X

// Load custom Goodix touch firmware

firmware = { #include "gd_5d.load.h" };


// Write the custom touch firmware into RAM_CMD

EVE_Hal_wrMem(RAM_CMD, firmware, sizeof(firmware));


// Update the write pointer register to start the execution

EVE_Hal_wr32(REG_CMD_WRITE, sizeof(firmware));


// Wait till EVE completes all the commands

while (EVE_Hal_rd32(REG_CMD_READ) != EVE_Hal_rd32(REG_CMD_WRITE));


// Reset the Touch CPU

EVE_Hal_wr32(REG_CPURESET, 2);


// Set GPIO0 low

EVE_Hal_wr32(REG_GPIO, 0x80);


// Set GPIO0 to output

EVE_Hal_wr32(REG_GPIO_DIR, 0x81);


// Wait for 100ms

EVE_Hal_sleep(100);


// Release the reset to Touch CPU

EVE_Hal_wr32(REG_CPURESET, 0);


// Wait for further 100ms

EVE_Hal_sleep(100);


// Set the GPIO0 to input

EVE_Hal_sleep(REG_GPIO_DIR, 0x80);


// DONE


Pseudo-code on how to use Goodix with I2C address 0x0140 in BT88X/FT81X


// Load custom Goodix touch firmware

firmware = { #include "gd_14.load.h" };


// Write the custom touch firmware into RAM_CMD

EVE_Hal_wrMem(RAM_CMD, firmware, sizeof(firmware));


// Update the write pointer register to start the execution

EVE_Hal_wr32(REG_CMD_WRITE, sizeof(firmware));


// Wait till EVE completes all the commands

while (EVE_Hal_rd32(REG_CMD_READ) != EVE_Hal_rd32(REG_CMD_WRITE));


// Reset the Touch CPU

EVE_Hal_wr32(REG_CPURESET, 2);


// Set GPIO0 low

EVE_Hal_wr32(REG_GPIO, 0x80);


// Set GPIO0 to output

EVE_Hal_wr32(REG_GPIO_DIR, 0x81);

EVE_Hal_sleep(100); // 100 ms


// Set GPIO0 high

EVE_Hal_wr32(REG_GPIO, 0x81);


// Release the reset to Touch CPU

EVE_Hal_wr32(REG_CPURESET, 0);

EVE_Hal_sleep(50); // 50 ms


// Set GPIO0 low

EVE_Hal_wr32((REG_GPIO, 0x80);

EVE_Hal_sleep(50); // 50 ms


// Set GPIO0 to input

EVE_Hal_wr32((REG_GPIO_DIR, 0x80);


// DONE
